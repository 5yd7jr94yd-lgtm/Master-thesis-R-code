# Master-thesis-R-code
This repository contains scripts used for age-depth modelling and figures presenting data from sediment cores from Trettetjørn, Norway.

Contents:

A_final_plum_model.qmd (age model)

A_Final_analysis.qmd (Pollen and spore percentages, ordination, diversity, zonation and influx analyses)

A_Temperature (simple temperature graph)

LOI_charcoal_core_comparison (Figure that plots the charcoal and LOI levels comparison on the same age axis)

alternative_plum_models (Alternative age-depth model configurations that was played around with modelling hiatus)
